# Security

## Reporting a vulnerability

Please report problems in the checker privately through GitHub:
**[Report a vulnerability](https://github.com/33rd-kk/local-image-gen-security/security/advisories/new)**
(the Security tab, "Report a vulnerability"). Do not open a public issue.

Examples: the checker sends a request that changes something, contacts an
address it was not given, reads more of a file than it says, or leaks
something through `--redact`. You will get an answer within a week; a fix
and an advisory follow when the report is confirmed.

A weakness in a tool that the checker or the profile is about (ComfyUI,
AUTOMATIC1111 / Forge, a hub) belongs to that tool's own project. Please
report it there.

Only the latest release of the checker gets fixes.
